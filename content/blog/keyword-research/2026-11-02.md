## Key Data Points to Include
- What overfitting is: model memorizes training data, fails on new data
- Detection: training accuracy >> validation accuracy, diverging loss curves
- Causes: insufficient data, model too complex, training too long, noise in data
- Difference from underfitting: underfitting = can't learn training data; overfitting = learns training data too well
- Prevention techniques (7): more data, regularization (L1/L2/dropout), early stopping, cross-validation, data augmentation, feature selection, model simplification
- When to use each: more data (always good if available), regularization (standard practice), early stopping (simple, effective), cross-validation (evaluation), data augmentation (limited data, CV/NLP), feature selection (many features), simplification (complex model)
- Python libraries: scikit-learn, TensorFlow, Keras, PyTorch for implementing prevention
- Validation strategy: train/validation/test split, never tune on test set
