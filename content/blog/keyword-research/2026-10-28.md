## Key Data Points to Include
- Three core areas: Linear algebra, calculus, probability/statistics
- Linear algebra: vectors, matrices, matrix multiplication, eigenvalues (basic to intermediate)
- Calculus: derivatives, gradients, chain rule (conceptual understanding sufficient for most)
- Statistics: probability, distributions, mean/variance, Bayes' rule (essential for all ML)
- Time to learn: 2-3 months for foundations if starting from scratch (realistic estimate)
- Different paths: Prompt engineering (minimal math) → Applied ML (moderate) → Research (deep)
- Industry reality: Most ML engineers don't calculate derivatives daily; libraries handle it
- Admission: You CAN start learning ML with basic high school algebra + willingness to learn
