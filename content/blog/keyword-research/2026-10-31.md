## Competitor Analysis

Reviewed 15 competitor pages (DataCamp, Coursera project lists, Medium articles, GitHub awesome lists, bootcamp blogs):
- Most are shallow lists with minimal implementation guidance
- Few explain WHY each project is good for beginners or WHAT you'll learn
- Missing: Difficulty ratings, realistic time estimates, tools/resources for each project
- Opportunity: Structured guide with clear learning outcomes per project
- Gap: Connection between project complexity and learning stage (do X before Y)
- Differentiator: Detailed project outlines with implementation steps, not just titles
- Missing: Free dataset sources, GPU-free alternatives, troubleshooting guidance

## Notes for Writing
- Start with why projects matter: portfolio, validation, learning through doing
- Provide selection criteria: match project to skill level, interests, career goals
- Each project needs: clear description, learning outcomes, difficulty rating, time estimate, required tools, free dataset source, implementation outline
- Progressive difficulty: easier projects first, more complex later
- Diverse project types: cover classical ML, NLP, computer vision, GenAI, agents
- Practical focus: all projects buildable with free tools, no GPU required
- Career angle: what each project demonstrates to employers
- Connection to courses: "take course X to learn skills for project Y"
- Honest about difficulty and time required
- Include troubleshooting tips and common mistakes
